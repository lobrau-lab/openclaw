# OpenClaw Personal Cheat Sheet

## General
- `openclaw status` : Check system status
- `openclaw doctor --fix` : Run self-healing routines
- `openclaw agents list` : List configured agents

## Security
- `openclaw security audit` : Basic security check
- `openclaw security audit --deep` : Deep probe verification

## Skills
- `openclaw skills install <slug>` : Install a new skill

## Paperclip Orchestration
- `paperclipai run` : Start the orchestration server
- `paperclipai doctor` : Diagnose orchestration issues
